# Projeto Conversor

Meu primeiro projeto usando C++
number-system-converter-project-binary-decimal-octal-and-hexadecimal

*****Tutorial*******

Escolha a base do numero de entrada digitando os valores abaixo:

1 - Binario 
2 - Decimal
3 - Octal 
4 - Hexadecimal

Digite o numero de entrada de até 10 dígitos.

Escolha a base do numero de saída digitando os valores abaixo:

1 - Binario 
2 - Decimal
3 - Octal 
4 - Hexadecimal

Obtenha o valor da conversão do numero de entrada para o numero de saída
